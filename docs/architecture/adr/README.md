# Architecture Decision Records

Recorded design decisions for Twilight Core — the context, the decision, and its
consequences — so the rationale behind the chain's architecture is legible to contributors
and reviewers.

| # | Title | Status |
|---|---|---|
| [0001](0001-coreslot-poa.md) | CoreSlot Proof-of-Authority — an independent validator module | Accepted |
| [0002](0002-rewards-emission.md) | Rewards emission and supply-threshold halving | Accepted |

The [architecture overview](../overview.md) is the read-first system map that these decisions
sit within.

Each ADR is curated from the internal design and validation record. Raw working notes,
experiments, and implementation reports remain local unless promoted into public
documentation. A superseding decision gets a new ADR that links back to the one it replaces.
